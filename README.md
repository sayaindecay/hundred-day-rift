# 백일의 틈 — 당신과 돌아오는 조사기록 (베타 0.1.0)

텍스트 기반 공포 탐사 로그라이트와 연애 서사를 합친 싱글플레이 웹게임입니다. 이미지 없이 글과 기록 서식만으로 진행하며, 서버 없이 정적 파일로 동작합니다.

> 이상현상을 조사하러 들어간 밤, 당신은 다른 시간에서 온 사람을 만난다. 무엇을 알아내고, 누구를 믿고, 어떤 약속을 남긴 채 함께 돌아올 것인가.

## 실행

- `index.html`을 브라우저로 바로 열면 됩니다(크롬·엣지·파이어폭스·사파리 최신판). 설치나 빌드가 필요 없습니다.
- 로컬 서버로 열고 싶다면: `powershell -ExecutionPolicy Bypass -File tools\serve.ps1 -Port 8765` → `http://localhost:8765/`
- 자동 검수: 서버로 연 뒤 `http://localhost:8765/tools/sim.html` → 실행. 원고 참조 검사와 4가지 플레이 정책 × 5인 × 40시드 자동 플레이를 돌립니다.

## 게임 소개

- **탐사자:** 여성 고정. 이름·나이·호칭, 성격 3축과 성향 태그, 배경 3종과 시작 도구, 능력치(각 1~3, 합계 8), 외모를 텍스트로 정합니다. 프로필은 브라우저에 3개까지 저장됩니다.
- **공략 인물 5인:** 고신백·이국세·남상범·한성백·한윤영. 관심 인물을 고르면 첫 사건에서 만나고, 네 사건과 세 번의 막간을 함께 지나며 관계가 움직입니다.
- **한 판:** 사건 4건(풀 5건, 사건마다 규칙 변형 2종) + 막간 3번 + 최종 겹침. 행동 슬롯 60개, 정상 완주 목표 45~60분.
- **조사:** 체력·침착·물자·균열을 관리합니다. 단서는 관찰·증언·기록·추정으로 나뉘고, 핵심 사실 두 개를 이으면 안전한 해결이 열립니다. 판정에 실패해도 꼭 필요한 사실은 대가를 치르고 얻습니다.
- **관계:** 신뢰와 마음, 인물마다 다른 핵심 약속, 관계 이정표로 진행됩니다. 결말은 연인 / 사랑하지만 헤어짐 / 동료 / 거리 두기. 고백과 연인 합의는 확률 없이 직접 고릅니다.
- **저장:** 선택할 때마다 자동 저장되고, 새로고침해도 같은 상태로 이어집니다. 저장은 이 브라우저에만 남으니 ‘저장 관리’에서 JSON으로 백업할 수 있습니다.
- **설정·접근성:** 글자 크기, 텍스트 속도, 명조/고딕, 테마, 움직임 줄이기, 잔혹 묘사 축소, 환경음(기본 꺼짐). 숫자키 1~9로 선택, Enter/Space로 진행, Esc로 메뉴. 360px 모바일부터 데스크톱까지 지원합니다.

**표현 수위:** 성인 수준의 공포·폭력·신체 훼손 묘사가 포함될 수 있습니다. 잔혹 묘사를 줄여도 단서·선택·결말은 같습니다. 연애 묘사는 고백·포옹·입맞춤까지입니다.

## 파일 구조

```
index.html          진입점
css/style.css       텍스트 UI
js/core.js          규칙 상수, 인물 명부, 난수, 텍스트 템플릿·조사(助詞), 조건식, 콘텐츠 등록
js/engine.js        한 판의 상태 전이 (DOM 없음)
js/store.js         localStorage 저장, 프로필 검증, JSON 가져오기·내보내기
js/validate.js      콘텐츠 자동 검수
js/audio.js         Web Audio 환경음 (외부 음원 없음)
js/dom.js           DOM 도우미, 모달 (사용자 입력은 항상 텍스트 노드)
js/creator.js       탐사자 생성기
js/ui.js            화면
content/common.js   서장·막간·최종 겹침·조기 종료 원고
content/cases/*.js  사건 5건 (행동·단서·규칙·대치·결말)
content/routes/*.js 공략 5인 루트
tools/sim.html      자동 검수
tools/serve.ps1     개발용 정적 서버
```

원고는 UI 코드와 분리되어 있습니다. 대사 한 줄은 `이름: 대사`, `이름[과거 기록]: 대사`(시간층), `나: 대사`, `# 장소·시각`, `※ 안내`, `! 경고` 형식이고, `---`는 페이지 구분입니다. `{name:은}`, `{call:이}`처럼 조사를 붙이는 토큰과 `{voice:완곡|중간|직설}`, `{v:변형A|변형B}`, `{gore:원문|축소문}` 같은 변형 토큰을 씁니다.

## 자동 검수 결과 (정책 4종 × 5인 × 40시드 = 800판)

| 정책 | 연인 엔딩 | 평균 균열 | 평균 슬롯 |
| --- | --- | --- | --- |
| 관계를 존중하는 선택, 단서대로 해결 | 5인 모두 40/40 | 77~80 | 약 57 |
| 40%는 아무 선택 | 17~26 / 40 | 77~80 | 약 57 |
| 무작위 | 1~2 / 40 | 약 66 | 약 40 |
| 위험 행동·빠른 결론 | 0 | 약 68 | 약 30 |

실행 오류·무한 진행 0건. 실제 사람의 플레이 시간과 재미는 아직 검증하지 않았습니다.
